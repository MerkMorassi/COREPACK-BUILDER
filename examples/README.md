# COREPACK Demo Example Files

This directory contains reference compiled artifacts generated by the **COREPACK Builder & Orchestration Platform (v2.0)** for the **TechLead-Analyst** preset:

| File | Type | Purpose |
| :--- | :--- | :--- |
| **`SYSTEM_PROMPT.md`** | Markdown | Complete compiled system prompt binding **Cognitive Substrate v3.0** with the **TechLead-Analyst** overlay and the mandated **Revenue-Grade Output Protocol**. |
| **`SKILL_MANIFEST.yml`** | YAML | Router-readable orchestration configuration defining sandbox filesystem read/write paths, permitted tool APIs, supported lifecycle states, and state transition logic. |
| **`schemas.ts`** | TypeScript / Zod | Production-grade Zod validation schemas enforcing deterministic payload parsing, non-negative integer limits, and double-entry ledger balance rules. |
| **`TEST_PROMPTS.md`** | Markdown | Diagnostic interrogation battery containing Baseline, Ambiguity Stress, and Destructive Refusal test cases with automated scoring rubrics. |

---

### How These Artifacts Fit Into Agent Architectures

1. **Deploying `SYSTEM_PROMPT.md`:** Load directly as the system instructions parameter when instantiating Gemini models (`gemini-3.7-flash` or `gemini-3.1-pro-preview`).
2. **Orchestrating with `SKILL_MANIFEST.yml`:** Multi-agent routers read this manifest to dynamically evaluate agent capabilities, sandbox permissions, and valid routing state transitions.
3. **Type-Checking with `schemas.ts`:** Used by ingress gateways, egress sanitizers, and tool callers to guarantee that agent outputs conform to strict runtime contracts.
4. **Validating with `TEST_PROMPTS.md`:** Automated CI/CD integration tests pass these prompts to measure the **Discrepancy Gap** and verify protocol adherence before production deployments.
